# 郭靖 · 射雕英雄传 · 漫画小说 10 页（严依小说）

> **原则**：像看漫画一样读小说，**信息量宁少勿多**；10 页只铺第一回开头一段，不抢跑后文。  
> **文本依据**：第一回《风雪惊变》通行正文（99csw 同回；99csw 被墙时用通行新修/三联系文本核对）。  
> **范围**：自「钱塘江浩浩江水……」起，至郭杨回家、李萍邀饭、相约打野味止。  
> **不画**：林中曲三杀官、盗大内、丘处机、完颜洪烈、灭门——皆属后文，本 10 页不进。  
> **形态**：竖版分镜漫画；姜云行式白描；气泡短句尽量贴近原文。

### 第 02 页 · 钱塘江边

**原文**：钱塘江浩浩江水……临安牛家村……乌桕叶子似火烧般红……正是八月天时……两株大松树下围着一堆村民……正自聚精会神的听着一个瘦削的老者说话。

**分格（3 格，留白多）**  
1. 宽景：江水绕村，乌桕红叶，斜阳  
2. 村口松树下人群背影  
3. 中景：村民围成一圈，中有说书人侧影  

**气泡/旁白**：旁白条「钱塘江边，牛家村。」  
**caption**：钱塘江浩浩江水，日日夜夜从临安牛家村边绕过。正是八月，乌桕叶红，松下围着一堆村民。

### 第 03 页 · 说书

**原文**：五十来岁，青布长袍；梨花木板；羯鼓；唱「小桃无主自开花……」；说金兵过后断墙残瓦、叶三姐一家惨祸；众村民咬牙切齿。

**分格（4 格）**  
1. 张十五特写：敲木板  
2. 鼓与木板特写  
3. 他开口唱/说，手势  
4. 村民愤怒、叹息的脸  

**气泡**：张「兵火过后……家家变成断墙残瓦。」（短）  
**caption**：那说话人五十来岁，青布长袍洗得褪色。他敲起梨花木板，说的是金兵过后的惨祸。

### 第 04 页 · 郭啸天请酒

**原文**：张十五自报名；《叶三姐节烈记》散场；托盘收钱；二十来岁大汉郭啸天请饮三杯；旁有白净面皮杨铁心。

**分格（4 格）**  
1. 张十五托盘，村民投铜钱  
2. 郭啸天上前：魁梧浓眉  
3. 郭「请先生去饮上三杯」  
4. 郭指杨：「这位是杨铁心杨兄弟。」  

**气泡**：郭「张先生，请饮三杯。」 张「素不相识，怎敢叨扰？」 郭「喝上三杯，那便相识了。」  
**caption**：村民中走出一个二十来岁的大汉，道：「小弟作东，请先生去饮上三杯。」他姓郭，名啸天；身旁是杨铁心。

### 第 05 页 · 曲三的小酒店

**原文**：村头小酒店；主人是跛子，撑两根拐杖；烫两壶黄酒；蚕豆、咸花生、豆腐干、咸蛋；曲三坐门口望落日，不向三人望一眼。

**分格（4 格）**  
1. 三人入小店  
2. 曲三拄拐、烫酒（背影或侧面）  
3. 桌上酒菜特写  
4. 曲三坐门口望天边斜阳  

**气泡**：郭「乡下地方，没了下酒之物，先生莫怪。」 张「有酒便好。」  
**caption**：小酒店主人是个跛子，慢慢烫了黄酒，摆出蚕豆花生，自行在门口望着落日，却不向三人望上一眼。

### 第 06 页 · 金兵与朝廷

**原文**：郭杨原是山东人，三年前南来；问金兵会否过江；张十五：拿主意的不是金国，而是临安大宋朝廷；郭啸天伸手在桌上重重一拍。

**分格（3–4 格）**  
1. 三人对酌  
2. 杨问「金兵会不会打过江来？」  
3. 张沉声说朝廷  
4. 郭拍案，杯筷跳起  

**气泡**：杨「金兵会不会打过江来？」 张「拿主意的，是临安的朝廷。」 郭「正是！」  
**caption**：张十五道，金兵来与不来，拿主意的却不是金国，而是临安的大宋朝廷。郭啸天伸手在桌上重重一拍。

### 第 07 页 · 痛骂秦桧

**原文**：说岳飞、秦桧；三人痛骂秦桧；曲三忽然嘿嘿两声冷笑；杨问「曲三，怎么了？」

**分格（4 格）**  
1. 张说岳爷爷被害  
2. 三人愤然举杯/拍桌  
3. 门口曲三背影，冷笑  
4. 杨回头：「曲三，怎么了？」  

**气泡**：张「……却把岳爷爷害死了。」 曲三「嘿嘿。」 杨「曲三，怎么了？」  
**caption**：三人只是痛骂秦桧。那跛子忽然嘿嘿两声冷笑。

### 第 08 页 · 罪魁是谁

**原文**：曲三：想要杀岳爷爷议和的，罪魁祸首却不是秦桧……岳爷一心灭金迎回徽钦，这两个皇帝一回来，高宗又做甚么？说完一跷一拐又去望天。

**分格（3 格，沉）**  
1. 曲三开口，三人一怔  
2. 曲三：「罪魁……只怕不是秦桧。」（气泡宜短）  
3. 他撑拐走开，又坐门边望天  

**气泡**：曲「罪魁祸首，却不是秦桧。」 三人「那么是谁？」  
**caption**：曲三道：「想要杀岳爷爷议和的，罪魁祸首却不是秦桧。」说了这几句，一跷一拐又去坐在门边望天。

### 第 09 页 · 醉别

**原文**：张十五醉，告辞往临安；口中念《满江红》「靖康耻，犹未雪……」；郭付酒钱，与杨并肩回家，比邻而居。

**分格（4 格）**  
1. 张脚步踉跄出门  
2. 他背影喃喃（气泡可写半句「靖康耻……」）  
3. 郭付账  
4. 郭杨并肩走在村道，暮色  

**气泡**：张「靖康耻，犹未雪……」  
**caption**：张十五喝得醺醺大醉，向东往临安而去。郭啸天付了酒钱，和杨铁心并肩回家。他两人比邻而居。

### 第 10 页 · 李萍赶鸡

**原文**：李氏正在赶鸡入笼，笑邀杨叔叔来吃饭，宰一只鸡；杨笑说再扰；相约今儿晚一起去打野味。

**分格（4 格）**  
1. 家门，李萍赶鸡  
2. 李笑：「杨叔叔，来吃饭吧。」  
3. 杨答应，三人和气  
4. 郭杨点头：今晚去打野味（夜色将临，收束）  

**气泡**：李「哥儿俩又喝饱了酒啦。」 李「宰一只鸡。」 郭「今儿晚咱一起去打。」  
**caption**：郭啸天的浑家李氏正在赶鸡入笼，笑道请杨铁心来吃饭。当晚，两人约了去打野味。
