# 线索表字段说明（配合 couple-leads-tracker.csv）

用 Excel / WPS / Numbers 打开 `couple-leads-tracker.csv` 即可填。

| 字段 | 怎么填 |
|------|--------|
| 编号 | 1、2、3… |
| 姓名/称呼 | 张姐、李总，不必全名 |
| 行业/生意 | 餐饮、家装、教培机构、保险经纪… |
| 认识途径 | 同学家长 / 朋友介绍 / 以前客户… |
| 城市 | 默认贵阳 |
| 联系方式 | 微信备注名即可，注意隐私 |
| 访谈日期 | YYYY-MM-DD |
| 访谈方式 | 当面 / 电话 / 微信语音 |
| 核心痛点一句话 | 越具体越好，避免只写「很忙」 |
| 现在怎么解决 | 自己做 / 员工 / 外包 / 不做 |
| 是否用过AI | 是/否/用过但放弃 |
| AI态度 | 好奇 / 排斥 / 已在用 |
| 更想要的档位 | A1 / B1 / C1 / D1 / 暂无 |
| 价格感受 | 原话或区间，如「一千以内」 |
| 是否愿再联系 | 是/否 |
| 是否可转介绍 | 是/否/已介绍谁 |
| 建议下一步 | 约A1 / 发菜单 / 暂缓 / 淘汰 |
| 负责人 | 一般填「老婆」；关键交付填「飞雪」 |
| 状态 | 待约 / 已约 / 已访谈 / 体验中 / 已付费 / 暂缓 |
| 备注 | 竞品、顾虑、方便联系的时间段 |

**状态建议只在这些词里选**，方便筛选。
