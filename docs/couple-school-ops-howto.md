# 观山湖外国语实验中学片区 · 具体怎么做（操作手册）

**执行人**：薰衣草（全日前线）+ 飞雪（业余交付）  
**现阶段产品**：P1 家长 AI 上手 → P2 家庭装机包 → P3 月陪跑  
**不做**：学科培训、保证提分、先租门面  

---

## 〇、人家为啥要听你们说？

家长不缺「鸡汤」和广告，缺的是：**有人懂我的烦、当场能减负、不像骗子补习班。**

你们能站得住的理由只有这几条（对外就讲这些）：

| 理由 | 怎么讲 | 别怎么讲 |
|------|--------|----------|
| **减的是家长的活，不是给孩子加课** | 「我们不教孩子刷题，是帮你写给老师的说明、整理群通知、少熬夜。」 | 「保证成绩」「名师」「冲刺」 |
| **当场能看见结果** | 「20 分钟给你搞定一封今晚就能发的消息。」 | 「先办卡，以后再学」 |
| **有人全日跟得上** | 「白天找薰衣草，她专职陪你把工具用起来。」 | 「加个群自己看教程」 |
| **男主人会 AI、但不住校门口忽悠** | 「技术我爱人把关，我负责陪你一步步做。」 | 吹「AI 公司」「国家级平台」 |
| **就在这个学校圈** | 「都是本校附近家长，听得懂咱们班级群有多烦。」 | 装外地连锁品牌 |

**一句话信任钩子（背熟）**  
> 我也是家长圈的人。我不卖补习。我只帮你把手机里的 AI 用起来，今晚就能少写半小时字、少生一回气。

没有这条「减负 + 当场结果」，人家没理由听；有了，才有下一句「要不要约 90 分钟系统搞一次」。

## 一、总顺序（先做什么、后做什么）

```
第1步 准备话术与工具（2–3天）
  → 第2步 混脸熟 + 加微信（1–2周）
  → 第3步 约访谈/送小忙（同步进行）
  → 第4步 约 P1 体验（有信任后）
  → 第5步 转 P2/P3 或结束跟进
```

**铁律**：没做完第 1 步，不要去校门口发传单式推销。  
**铁律**：第 2–3 步以「帮忙、请教」为主，不要一开口报价。

## 二、第 1 步：准备（飞雪为主，薰衣草会背）

### 1.1 准备 3 样「能当场秀」的东西

飞雪做，薰衣草练到能演示：

1. **场景 A**：班级群长通知 → 30 秒整理成「今日待办 3 条」  
2. **场景 B**：请假/情况说明 → 生成一封得体短信给班主任  
3. **场景 C**：孩子玩手机争执 → 生成一段不激化矛盾的沟通话术  

每个场景写成手机备忘录里的**固定提示词**，演示时复制粘贴即可。

### 1.2 准备对外三句话（薰衣草背）

1. 我们是谁：本校附近，专职帮家长用 AI 减负，不办补习班。  
2. 我们帮什么：通知、沟通老师、家庭对话、周末安排。  
3. 怎么开始：先送你一个小忙 / 请教你 15 分钟；合适再约 90 分钟上手。  

### 1.3 准备物料

- 线索表：`couple-leads-tracker.csv`  
- 微信签名备注：如「薰衣草｜家长AI减负（非补习）」  
- 两个备用咖啡馆地址（安静、好停车）  
- 飞雪与薰衣草的联络窗口：午休 + 晚上 20:30 后  

**完成标准**：薰衣草能独立演示场景 A/B 中至少一个，不看稿。

## 三、第 2 步：怎么找客户（具体到动作）

### 3.1 客户从哪来（按优先级）

| 优先级 | 来源 | 怎么做 | 目标 |
|--------|------|--------|------|
| ★★★ | 已有微信里的本校/周边家长 | 逐个私聊，不群发广告 | 先挖 20 个可聊的人 |
| ★★★ | 接送高峰「脸熟」 | 早晚各去 1 次，只打招呼 | 每周新加 3–5 人 |
| ★★ | 邻居、物业、打印店、托管边缘店 | 进店寒暄，说明帮家长减负 | 每周 2 家 |
| ★★ | 转介绍 | 每次聊完问「还有谁也被群通知折磨」 | 每人要 1 个介绍 |
| ★ | 班级群/业主群 | **只在被问到时**出现，不主动硬广 | 慎用 |

### 3.2 接送点行为规范（重要）

**做**  
- 站在不堵路、不挡门的位置  
- 先帮个小忙（看包、指路、递个纸）再交换微信  
- 对方赶时间就说「加个微信，不耽误你接人」  

**不做**  
- 堵校门发传单、拉横幅、大声喊  
- 一加微信就发长链接和价目表  
- 和孩子搭话推销（只跟家长）  

### 3.3 加微信后 24 小时内发什么（模板）

```
X妈妈你好，我是薰衣草（观山湖外国语实验中学附近）。
我专职帮家长用 AI 减负：整理班级通知、写给老师的说明之类，不做补习。
你要是哪天被群消息淹了，可以把通知转我，我示范怎么一键整理成待办。
不打扰，慢慢聊～
```

## 四、第 3 步：找到后怎么沟通（分三种开口）

### 开口 1：请教式（最安全，用于生人）

> 想请教你 15 分钟：你们班群通知多不多？你一般怎么整理的？  
> 我们在做家长减负的小事，想听听真实情况，不收费。

→ 按访谈 7 问聊，填线索表。

### 开口 2：送小忙式（最容易建立信任）

> 你把今天下午那条最长的群通知转我，我 5 分钟整理成「今天只要做 3 件事」发你看看。  
> 你觉得有用，我们再聊别的；没用你当我没说。

→ **当场出结果**。这是「人家为啥要听」的关键证据。

### 开口 3：熟人直说式

> 我这阵子全日在做一件事：教家长用 AI 写老师沟通、理通知。  
> 不做题、不提分。你要不要找个周末 90 分钟，我陪你把手机设置好？

→ 直接约 P1。

## 五、沟通全流程（从加微信到约课）

```
加微信
  → 24h 内发介绍短消息（第三节模板）
  → 找机会：开口2送小忙（整理一条真通知）
  → 对方说有用
  → 约「咖啡馆 90 分钟 P1」（给两个时间选项）
  → P1 现场带走会用的能力
  → 结束时问：要不要把模板装全套（P2）/ 要不要按月有人问（P3）
  → 不需要就友好结束，保持联系，偶尔送小忙
```

### 约 P1 话术

> 周六上午 10 点或周日下午 3 点，你方便哪个？  
> 就在附近咖啡馆，90 分钟。结束时你要能自己再做一遍整理通知和写信。  
> 体验价 XX 元（朋友价可再低），不满意这节就当请你喝杯咖啡。

### 现场 P1 怎么控场（薰衣草可带做时）

1. 0–10 分：听她最烦哪一件  
2. 10–40 分：只攻这一个场景，反复练到她会  
3. 40–70 分：再加一个场景（写信或催学话术）  
4. 70–90 分：她独立操作一遍；发提示词到她微信；约回访  

飞雪若无法到场：用标准流程短视频/屏幕录制 + 薰衣草盯着对方手机操作。

## 六、对方会怎么拒绝 & 怎么回

| 对方说 | 你可以回 |
|--------|----------|
| 没时间 | 「那就 5 分钟：你发一条通知给我，我整理好发你。有用再约，没用当交个朋友。」 |
| 我自己会用 AI | 「太好了。那你平时用它处理班群吗？我请教你怎么用的，也看看我们模板有没有漏的。」 |
| 是不是补习班 | 「明确不是。我们碰都不碰孩子功课，只帮家长减负。」 |
| 多少钱 | 「先送你一个小忙。系统上手 90 分钟一般在 99–299，装全套模板另算。你先感受有没有用。」 |
| 我再看看 | 「行。我把整理通知的提示词发你。你用了觉得别扭再叫我。」（标记黄灯，3–7 天回访一次） |
| 丈夫/家人不同意 | 「理解。你把演示结果给他看就行，我们不拉人办卡。」 |

## 七、按天执行表（薰衣草）

### 每日（工作日，约 3–4 小时有效即可）

| 时段 | 做什么 |
|------|--------|
| 上午 | 回消息、补线索表、约访谈/P1；练习 1 遍演示 |
| 接送高峰（按学校实际） | 到学校周边出现 20–30 分钟：打招呼、加微信 |
| 下午 | 送小忙（整理通知）、回访、写「晚间问题清单」给飞雪 |
| 晚上 20:30 后 | 与飞雪对一次黄灯问题（合并问，不超过 20 分钟） |

### 每周目标（起步 4 周）

| 指标 | 数量 |
|------|------|
| 新加微信（家长） | ≥5 |
| 送小忙（真整理通知/写信） | ≥5 |
| 有效访谈 | ≥2 |
| 约成 P1 | 第 3–4 周起争取每周 0–1，不硬凑 |

### 飞雪每周固定

- 维护 3 个演示提示词，保证好用  
- 周末可主讲 1 场 P1，或验收薰衣草带的场次  
- 不接白天连环电话，只按红黄绿灯

## 八、从「听你说」到「愿付钱」的判断

对方出现这些信号，再谈 P1/P2：

- 主动再发第二条通知让你整理  
- 问「教我一下怎么自己做」  
- 问价格、问时间  
- 愿意介绍另一个妈妈  

若只已读不回：最多温和跟 2 次，转入「每月偶然送价值」，别追。

## 十、记住这三句就够临场用

1. **我们不补习，帮家长减负。**  
2. **你发一条通知给我，我先免费整理给你看。**  
3. **有用再约 90 分钟，让你自己也会做。**  

客户听你说，是因为你先给了结果，不是因为你先给了梦想。
